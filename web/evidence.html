Evidence

Every number here is computed in your browser from files in the repository: the saved walls, their run logs, and the hand labels written for each lecture before any model saw it.

Finding the rules

Labels: every rule the teacher states that the library can check, marked by hand from a full reading of the transcript and committed before the first run. A card counts as matching when it names the same library rule within three sentences of a labelled statement.

The check at work

Each generated lab measures its own quantity with a probe. If the probe disagrees with the exact physics by more than 0.5% at any of five points, the lab is sent back once with the numbers; if it still disagrees, it is not shown.

The library against known answers

The test suite runs on every push. It checks each physics model against textbook values and against a second, independent method; checks that rules which hold stop holding when the physics changes; and runs 20 frozen lecture moments (their answer key is hashed in the test) where every verdict must match and every limit must match the key.
