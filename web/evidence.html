Measured, not claimed.

Every number here is computed in your browser from files in the repository: the saved walls, their call logs, and the hand labels written for each lecture before any model saw it.

Finding the rules.

The labels list every rule the teacher states that the library can check, marked by hand from a full reading of the transcript and committed before the first run. A rule counts as found when a card names the same library rule within three sentences of the labelled statement.

The check at work.

Each generated lab measures its own quantity with a probe. If the probe disagrees with the exact physics by more than 0.5% at any of five points, the lab goes back once with the numbers; if it still disagrees, it is not shown.

The library against known answers.

The test suite runs on every push. It checks each physics model against textbook values and against a second, independent method; checks that rules which hold stop holding when the physics changes; and runs 20 frozen lecture moments whose answer key is fingerprinted in the test, where every verdict must match. npm run verify re-checks every saved wall offline, with no keys.
