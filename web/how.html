The model finds the rules. Plain code decides.

Kimi K3.1 Pro on Cerebras does the reading and the writing, through two OpenClaw agents. Everything that could mislead a student is decided by ordinary, tested code.

Rule finderAn OpenClaw agent reads the transcript and lists each rule the teacher states, with the quote and the library rule that tests it.
Quote checkEach quote must appear in the transcript word for word. The minute comes from the transcript, never from the model.
Physics librarySweeps the rule's range against first-principles physics and decides: holds, breaks at a value, holds only in a band, or does not hold.
Lab buildersOne OpenClaw agent per rule, all at once, writes an animation and a probe that measures the same quantity.
Probe checkThe lab's own physics must match the exact answer within 0.5% at five points, or it gets one repair round, or it is not shown.

What the verdicts mean

Every rule is compared with the exact answer across the range the teacher means. The gap is the relative error, |rule − exact| ÷ |exact|, and the line is 1%.

  • holds: within 1% everywhere in the range.
  • breaks at X: within 1% up to X, then past it. X is found by bisection on the exact model.
  • holds between A and B: within 1% only inside a band (the rule of 72 is the classic case).
  • does not hold: past 1% everywhere in the range.

The exact side is computed two independent ways where it matters: the pendulum's large-swing period by the arithmetic-geometric mean and by RK4 integration of the swing, falling with drag by the closed form and by RK4. The test suite checks both against each other and against textbook values, and checks that rules which hold stop holding when the physics changes (a stiffer spring, air drag, a heavy planet).

Where model-written code runs

On the server, a lab's probe runs in a worker thread with a memory cap, inside an empty JavaScript context with string code generation turned off and a time limit per call. The test suite tries to reach the process, files and the network from inside it, and tries endless loops and memory bombs. In your browser, each lab runs in a sandboxed frame with its own origin and no network; the page sends it numbers and shows model-written text as plain text.

What it works on

LIVE LAB works on spoken physics and maths rules that have a formula the library covers. Other statements in a lecture are listed under each wall as skipped, with the reason. Live building runs on Kimi K3.1 Pro on Cerebras during its access period; every saved wall stays open and playable after that. A lecture’s minute marks are estimated from word position when its transcript is timed only by chapter.
